# 桌面 NativeSync 接入管理

本轮实现“全局设置 → NativeSync”入口，通过宿主现有Feature、preload注册和设置扩展加载。
没有在main.js、renderer.js或全局设置核心中新增针对NativeSync的分支。

## 使用方式

从VCPChat的全局设置入口打开设置，在左侧选择NativeSync。

- 首次接入：沿用「服务器连接」中已保存的HTTPS地址和Key，选择1—8个已保存的话题，点击「检查连接与历史」。
- 检查仅做本地读取及已有服务端GET查询，不写历史、Journal或执行任务。比对无冲突后，勾选确认并保存。
- 新接入会同步所选历史，以及手机续聊所需的助手设定（包括提示词）；确认界面明确说明目的服务器和范围。
  Key仍由现有设置管理，不复制进NativeSync配置，也不返回到该面板。
- 保存后当前运行的Bridge保持原样。通过「退出VCPChat」执行原生受保护退出，再从原启动入口重新打开生效。
  第一版不提供运行中切换，也不在退出被拒绝时强行重启。
- 已有绑定可停用、恢复，设备身份、话题范围、state、游标和Outbox不被重置；已有仅同步历史的配置不会被自动改成发布私密执行设定。
  停用后原已绑定历史沿用现有只读恢复保护；恢复时检查并使用原绑定。

本版沿用selected模式及服务端已有话题绑定。服务端尚未配置的手机接续话题会明确提示，不自动创建授权。
已有绑定的范围在面板中锁定，范围扩展仍走现有受控转换。Source模式在此只读显示，不自动降为selected。
附件和群聊的额外完整应用验收仍属于后续工作。

## 接口与持久化

新增三个仅向chat角色暴露的窄IPC：nativeSyncSetupOverview、nativeSyncSetupPreview、nativeSyncSetupSave。
主进程再次验证调用来自本宿主主窗口的主frame，其他窗口或iframe不能调用。
概览仅返回服务器origin、话题名称/身份、配置版本摘要和聚合同步状态，不返回Key、提示词或聊天正文。

预览绑定当前配置版本、所选文件指纹、既有服务器身份及确认token。保存时再次检查配置、历史和绑定，
外部变更或过期确认被拒绝。原生历史读取经HistoryMutationQueue串行，配置原子写入复用durableJson。
受保护状态丢失、损坏或路径别名不会被当成新接入；面板不执行数据修复或删除恢复文件。

持久化沿用原connection.json字段。connection.js只提取既有语义校验供预览复用，协议、state格式与数据库不变。
保存结果与启动时配置分别显示：未重新启动前，不把“下次停用”说成“当前已停止”。

## 发布与验证

原77文件运行包增加一个六文件Feature，共83文件。完整本机宿主指纹增加Feature加载器、preload注册、
设置扩展、schema和quitAdmission能力；旧宿主不能仅凭同名VCPChat被当作兼容目标。
安装路径白名单只增加本项目Feature目录，公共夹具标识、专用本机根、摘要核对和数据保护限制保持原样。

定向回归覆盖首次只读预览/确认、凭据不复制、历史变化、配置变化、连接变化、选择限制、身份/范围保留、
Source只读、状态损坏、路径别名/硬链接、原生话题删除和主frame限制。
完整Electron场景settings覆盖实际设置页的首次接入、过期历史拒绝、重开、停用与再启用；原九个整机场景继续保留。
最终结果、候选摘要和固定环境安装回执在施工结束后另行记录，不以先前版本测试替代本版验收。

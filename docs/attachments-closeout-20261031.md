## 修复结果

1. 桌面原生历史把附件身份放在 `_fileManagerData`，上传原先只读取外层 ID。
   现在文件、图片帧、缓存和消息绑定使用既有规范化身份，不新增身份或同步协议。
2. FileManager 回填会生成本机时间戳、解析结果及 null 默认值。
   现在只补本机句柄，保留已接受的创建时间、提取文本和帧引用，避免内容指纹变化或原始元数据校验失败。
3. 宿主旧 PDF 解析器会误读池化 Buffer；改为传入独立 Uint8Array。
   Linux 图片回退使用已安装的 pdfinfo/pdftocairo，避免导入会退出进程的 pdf-poppler 包。
   该改动保留为带前后摘要的宿主补丁，不把整个宿主复制进 NativeSync 核心。
4. 文件落盘后原先未通知桌面刷新，手机图片会暂留破图。
   现在复用既有历史通知及重试；完整应用断言检查无需刷新即实际解码成功。

产品改动只有 NativeSync 的 attachments/runtime 两个模块与一项 PDF 宿主兼容补丁。
没有更改公开协议、state 格式、AA 查询接口或数据库结构，没有新增修复工具、隔离协议或裁决框架。

# 本机全量同步与自动续聊

全量范围来自原生 Agents、AgentGroups 配置及其话题历史，包含已提交的辅助对话和后续新增内容。
首次导入分批进行，之后沿用原消息级增量同步。附件仍受既有格式和20 MB限制，缺失或不支持项目不算完成。

## 接入

桌面「全局设置 → NativeSync」选择「全部 Agent／群聊」。界面显示本机设备标识；
后端维护者须事先在 NativeSyncFullSources 中批准相同的 sourceId、deviceId，明确设置
executionMode 为 all-supported。模型图片能力由该可信来源的 imageModels 列表指定，缺省不推测。
这些绑定项不含Key；认证继续使用桌面已有服务器设置，客户端不能自行创建服务器授权。

填写已配置的Source ID，检查目标服务器与目录数量，再确认全部历史、支持的附件、
续聊必要设定（含提示词）及未来新增会话的范围。保存后正常退出并重开。
已有选定话题转换前必须结清原队列并核对原历史域；原设备、空间、游标和回执保持。
已有受限Source扩围继续使用原受控流程，本入口不代替其单独批准。

全量历史读取不依赖逐话题登记。服务器和客户端都开启自动续聊后，受支持话题的执行快照自动发布，
来源和归属由服务器核对。普通可移植提示词不需要逐话题服务器别名；已有受信别名绑定的原生引用仍由AgentManager解析；缺少绑定时显示不可续聊原因。
配置更新只影响新请求，已受理请求和群步骤保留原冻结快照。JEV/game、缺少配置或依赖桌面工作区的会话显示原因。

手机需创建明确的Source配对，授权该来源及未来话题；原选定话题会话不会自动扩权。
附件在原会话内预览、保存。Android安装可能需要手机VPN才能访问安装链路，这不代表本机消息同步需要公网模型。

## 进度与资源

目录发现不预载所有历史正文。后台只驻留一个导入话题的正文快照，重开按计划和检查点继续。
原生写入按需准备校验基线；单话题仍采用宿主JSON历史文件，身份/摘要索引仍随数据规模增长。
此版本不承诺任意大库的恒定内存或导入时间。

配置发布独立于历史推进，一轮处理一个话题；启动分页核对版本，后续仅发布投影后的配置变化。
某个会话配置被拒绝会记录该会话原因，其他会话可继续发布；修正后自动核对。
历史接入、附件就绪、续聊配置待就绪与异常分别显示，不能只凭队列为空判断整个来源完成。

## 兼容回退

支持目标是保留Source历史同步和读取，停用新增自动续聊。仅在停止本项目实例、导入/队列结清且没有
待处理执行和未知原生任务时进行；不能清理状态以满足前提。先运行包内工具：

```sh
python3 tools/source_compat.py prepare --root <本机固定或标记测试目录> --receipt <目录外的新回执路径>
```

它仅移除本来源新增的executionMode及来源级imageModels配置键，保存非凭据恢复信息和前后摘要，
不会恢复旧Source范围、数据库、state、游标或执行快照。若其他来源也使用新键，工具拒绝擅自修改其他来源。
然后使用已有本机安装器回退代码。本轮声明的目标候选为Android附件修复版5a4ee82，
具体回退组合必须以实际运行回执为准，不能任意换成更老版本。

再次安装新代码后，在停止状态下恢复这些键：

```sh
python3 tools/source_compat.py restore --receipt <同一回执路径>
```

安装器始终只修改代码。出现配置漂移、未结清工作或兼容检查失败时保留现场，使用新候选向前恢复。
本说明只适用于本机合成环境；真实资料库切换、长期手机入口及服务器部署另行安排。
